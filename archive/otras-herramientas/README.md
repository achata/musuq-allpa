# Herramientas retiradas de la interfaz

Se conservan los fragmentos del antiguo bloque «Otras herramientas» y Neugrac en TikTok para poder reactivarlos. La parcela interactiva sigue accesible dentro de cada parcela registrada.

Estos archivos no se incluyen en `dist/` ni se sirven públicamente. Para reactivarlos, revisar enlaces, traducciones y contexto de parcela antes de volver a insertarlos.
